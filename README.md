# LASA Medical Camp

Bilingual (English / Español) website for the LASA Foundation Medical Camp, themed to match the main LASA Foundation site.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Routes

| Path | Page |
|------|------|
| `/` | Bilingual splash entry |
| `/en` | English clinic site |
| `/es` | Spanish clinic site |
| `/en/schedule` | English schedule (placeholder) |
| `/es/horario` | Spanish schedule (placeholder) |
| `/en/privacy` | English privacy notice |
| `/es/privacidad` | Spanish privacy notice |

Contact details are sourced from LASA Foundation (`40 Old Ferry Road, Lowell, MA`, `info@lasane.org`).
